# RheoMarine-SLO — GitHub milestones

These native GitHub milestones organize the project by evidence gates. They deliberately have no due dates until the RISTANC timetable is confirmed.

| Milestone | Scope | Exit criteria |
|---|---|---|
| M0 — Data readiness | HFR-NAdr, QC, observational datasets, permissions and provenance | Required datasets inventoried; coverage, QC, licensing/access conditions and gaps documented |
| M1 — Baseline transport validation | Independent Eulerian M0 baseline and HFR handoff | Reproducible pilot runs; QC-preserving inputs; quantitative diagnostics and limitations documented |
| M2 — Independent laboratory evidence | µFTIR microplastics pilot and sample logistics | Sampling protocol/permissions resolved; laboratory report received; blanks and QA/QC reviewed |
| M3 — Evidence-gated rheological extension | EPS/aggregation/reology extensions | Parameters supported by independent measurements; extension compared against M0 baseline; unsupported effects excluded |
| M4 — Predictive validation | Independent observations, sensitivity and uncertainty | Predefined validation metrics computed on independent evidence; uncertainty and failure cases reported |
| M5 — RISTANC delivery and dissemination | Deliverables, reproducibility, reporting and dissemination | Required deliverables complete; evidence linked; reproducible archive and dissemination record checked |

## Governance

- A milestone is complete only when its exit criteria are evidenced in merged issues/PRs and linked deliverables.
- Code implementation alone does not close a scientific validation milestone.
- Supplier quotations establish feasibility and price, not completed analyses or scientific validation.
- Contacts and expressions of interest are not institutional partnerships unless formally confirmed.
- Milestone due dates are intentionally unset pending confirmation of the official RISTANC calendar.
- The milestone creation workflow is idempotent: rerunning it updates descriptions and does not create duplicates.
