# RheoMarine-SLO — GitHub milestones

These native GitHub milestones organize the project by evidence gates. Dates below are a **planning baseline for a 12-month implementation**, not a substitute for the signed funding agreement. The RISTANC call permits projects of 6–12 months. The project starts on the funding-agreement signature date, which cannot be earlier than 1 January 2027, and must end no later than 28 February 2028. The final project report is due within 30 days after project completion. If the approved duration or start date differs, milestone dates must be recalculated.

## External call deadlines

- **28 November 2026, 23:59 CET** — application submission deadline.
- **By 15 December 2026** — expected publication of results.
- **1 January 2027** — earliest permitted project start.
- **28 February 2028** — absolute latest project completion date.

## Milestone schedule (12-month planning baseline)

| Milestone | Target date | Scope | Exit criteria |
|---|---:|---|---|
| M0 — Data readiness | 2027-01-31 | HFR-NAdr, QC, observational datasets, permissions and provenance | Required datasets inventoried; coverage, QC, licensing/access conditions and gaps documented |
| M1 — Baseline transport validation | 2027-04-30 | Independent Eulerian M0 baseline and HFR handoff | Reproducible pilot runs; QC-preserving inputs; quantitative diagnostics and limitations documented |
| M2 — Independent laboratory evidence | 2027-06-30 | µFTIR microplastics pilot and sample logistics | Sampling protocol/permissions resolved; laboratory report received; blanks and QA/QC reviewed |
| M3 — Evidence-gated rheological extension | 2027-09-30 | EPS/aggregation/reology extensions | Parameters supported by independent measurements; extension compared against M0 baseline; unsupported effects excluded |
| M4 — Predictive validation | 2027-12-31 | Independent observations, sensitivity and uncertainty | Predefined validation metrics computed on independent evidence; uncertainty and failure cases reported |
| M5 — RISTANC delivery and dissemination | 2028-02-28 | Deliverables, reproducibility, reporting and dissemination | Required deliverables complete; evidence linked; reproducible archive and dissemination record checked |

## Governance

- The application deadline and project implementation deadlines are distinct.
- Milestone dates are planning targets under a 12-month scenario; confirm/revise them after the funding decision and signature of the funding agreement.
- A milestone is complete only when its exit criteria are evidenced in merged issues/PRs and linked deliverables.
- Code implementation alone does not close a scientific validation milestone.
- Supplier quotations establish feasibility and price, not completed analyses or scientific validation.
- Contacts and expressions of interest are not institutional partnerships unless formally confirmed.
- The milestone creation workflow is idempotent: rerunning it updates descriptions and due dates and does not create duplicates.
