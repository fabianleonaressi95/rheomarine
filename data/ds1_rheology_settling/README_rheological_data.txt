1. Title of Dataset: Rheological_data
Data were collected in the Warsaw Univesity of Technology, Faculty of Chemistry

2. Folder List: 

Folder Rheological_data contains 3 sub-folders: flow_data, amplitude_sweep, gelling_time. Each folder contains 
a data file for all experimental sets:

AS_XG0.5.csv
AS_XG1.csv
AS_CR0.5.csv
AS_CR1.csv
AS_XGCR0.5.csv
AS_XGCR1.csv
additionally flow_data contains AS.csv 

Names refer to solutions - each solution was composed of artificial seawater (AS) preraped according to a standard (ASTM, 2013. Standard Practice for  the Preparation of Substitute Ocean Water) and
dissolved polymer: XG - xanthan gum, CR - kappa-carrageenan, XGCR - mixture of xanthan gum and kappa-carrageenan (4:1 proportion) in two concentrations 0.5 g/L and 1 g/L.

3. Additional related data collected that was not included in the current data package: 
Data on settling of partices in solutions stored in Settling_experiments folder
	
4. Methodological information:
Description of methods used for collection/generation of data: 
Presented in a paper linked to this dataset.

5. Data-specific information:

*.csv files contain the following variables: 
- flow properties:
variables stored in seven columns: shear rate [1/s], shear stress [Pa], viscosity [Pa s], speed [1/min], time [s],torque [µN m], 1st normal stress difference [Pa].
- amplitude sweeps: 
variables stored in five columns: gamma - strain [%], tau - shear stress [Pa], StorageMod -storage modulus [Pa], Loss Mod - loss modulus [Pa], ComplVisc - Complex viscosity [Pa s]. 
- gelling time: 
variables stored in five columns: interval time [s], shear rate [1/s], shear stress [Pa], viscosity [Pa s], speed [1/min]
