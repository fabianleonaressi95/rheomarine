1. Title of Dataset: Dimensions_of_particles
Data were collected in Laboratory of Hydrodynamic Micromodels, Institute of Geophysics, Polish Academy of Sciences

2. Folder List: 

Folder Dimensions_of_particles contains 14 csv files with dimensions of particles. For each particle type, a group of representative particles was measured.

3. Additional related data collected that was not included in the current data package: 
Data with the results of settling tests stored in Settling_experiments folder and data on rheological properties of solutions stored in Rheological_data folder and
	
4. Methodological information:

Detailed description of methods used for collection/generation of data: 
Presented in a paper linked to this dataset.

General description: Dimensions of test partices were measured using cameras with macrolenses and image analysis methods (beside S_PS for which diameter was provided by the manufacturer). 
For each particle type, from few to over one hunderd of particles were measured.The following dimensions of particles were measured (L –  length, I – breadth, and S – thickness).

5. Data-specific information:
 
csv file name indicates the type of a partice in the following format:
P_A_ind where P indicates type of particle (S – sphere, D – disk, R - rod, B - blade, I - irregulaer) 
A indicates polymer type (PS, POM, PET, PA), 
ind - indicates set of particles in terms of dimentsions (a, b, c) defined in the related paper and below,

Data were collected in three columns: L [mm], I [mm], S[mm]
where L - the longest dimension, length; I - the intermediate dimension, breadth; S - the shortest dimension, thickness
